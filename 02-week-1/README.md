Membangun fondasi yang akan dipakai sepanjang sisa kursus. Pemula tidak diterjunkan langsung ke Python — kita mulai dari yang familiar (Excel) dan deklaratif (SQL), supaya confidence terbangun bertahap.

## Tujuan Akhir Week 1

Setelah Week 1, peserta:
1. ✅ Punya environment kerja yang siap (VSCode + Python + Git + akun GitHub)
2. ✅ Bisa pakai Excel untuk data manipulation menengah (pivot, VLOOKUP, Power Query)
3. ✅ Bisa nulis SQL dasar (SELECT, WHERE, GROUP BY, ORDER BY) di SQLite & BigQuery
4. ✅ Paham descriptive statistics (mean, median, std, distribution)
5. ✅ Selesai 1 mini case study end-to-end

## Catatan Mentor

- Day 1 AM (Setup) sering jadi titik frustrasi — banyak install yang berpotensi error per OS. Sediakan extra waktu Q&A.
- Day 2 (Excel) jangan diremehkan — banyak pemula yang mengaku "sudah bisa Excel" tapi belum kuasai pivot/VLOOKUP dengan benar. Cek dengan latihan.
- Day 3 (SQL) adalah inti karir DA. Kalau peserta struggle di sini, alokasikan extra time.
- Day 4 (Stats) bisa terasa abstrak — selalu bawa kembali ke konteks bisnis.
