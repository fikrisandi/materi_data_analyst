# Pre-Week Modul 2 — Diferensiasi Profesi Data

## Tujuan Modul

Setelah membaca modul ini, peserta:
1. Bisa membedakan 7 profesi di ranah data (DA, DE, AE, DS, MLE, AIE, BI Dev) — apa yang dikerjakan, tools, output
2. Paham analogi restoran sebagai shortcut mental untuk mengingat perbedaan
3. Tahu jenjang karir lateral — kapan & bagaimana DA bisa pivot ke role lain
4. Memetakan skill overlap antar profesi sehingga belajar DA = fondasi untuk semua

## Durasi

~45 menit baca mandiri.

## Prasyarat

Sudah selesai Modul 1 (Selamat Datang & Potensi DA). Idealnya juga sudah jawab refleksi Modul 1.

## Format Output

- `materi.md` — modul tertulis (~3,000 kata)
- `cheatsheet.md` — tabel komparatif 7 profesi
- `mentor-notes.md` — briefing mentor
