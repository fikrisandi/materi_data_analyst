# Cheatsheet — Pre-Week Modul 2

## 7 Profesi Data dalam 1 Tabel

| Profesi | Fokus | Tools Khas | Output | Gaji Senior JKT |
|---|---|---|---|---|
| **DA** Data Analyst | Insight dari data existing | SQL, Excel, Tableau/PBI, Python | Dashboard, report | 22–40 jt |
| **DE** Data Engineer | Pipeline & infrastructure | SQL, Python, Spark, Airflow | ETL, warehouse | 30–55 jt |
| **AE** Analytics Engineer | Modeling di warehouse | dbt, SQL, Git | Tabel siap-pakai | 35–60 jt |
| **DS** Data Scientist | Modeling & eksperimen | Python (sklearn), R | Model prediktif | 30–60 jt |
| **MLE** ML Engineer | Productionize ML model | Python, Docker, K8s | ML system di prod | 40–70+ jt |
| **AIE** AI Engineer | Aplikasi AI (LLM, RAG) | LangChain, vector DB | Chatbot, AI agent | 40–80+ jt |
| **BI Dev** BI Developer | Dashboard enterprise | Power BI (DAX), Tableau | Enterprise dashboard | 20–35 jt |

## Analogi Restoran (mental shortcut)

- **DE** = Supplier bahan baku
- **AE** = Sous chef siapin mise en place
- **DA** = Chef racik menu spesial untuk tamu
- **DS** = Food scientist riset rasa baru
- **MLE** = Manajer pabrik makanan masal
- **AIE** = Chef pakai robot AI
- **BI Dev** = Food stylist plating cantik

## Skill yang Paling Overlap

**SQL** — wajib di semua profesi data. Mau ke mana pun, kuasai SQL dulu.

## Path Pivot dari DA

```
DA → AE → DE              (engineering-leaning)
DA → DS → MLE             (modeling-leaning)
DA → AIE                  (LLM/AI app)
DA → BI Dev → BI Lead     (visualization spesialis)
DA → Manager → Director   (managerial)
DA → Domain Specialist    (Product/Growth/Risk Analyst)
```

## 5 Pertanyaan Diagnostik untuk Pilih Profesi

1. **Cari jawaban** atau **bangun sistem**?
2. **Dalam 1 problem** atau **cepat ke banyak**?
3. **Bisnis/orang** atau **kode/sistem**?
4. **Eksperimen gagal-gagalan** atau **progress stabil**?
5. Comfort level dengan **English**?
