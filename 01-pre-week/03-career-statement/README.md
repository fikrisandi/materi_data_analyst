# Pre-Week Modul 3 — Career Statement & Skill Mapping

## Tujuan Modul

Setelah membaca modul ini, peserta:
1. Paham apa itu Career Statement dan kenapa penting (self-anchor)
2. Bisa menulis Career Statement personal dalam 1 paragraf yang clear
3. Sudah mengerjakan skill mapping self-assessment
4. Sudah memilih 1 target role spesifik di LinkedIn dan menyimpannya sebagai referensi

## Durasi

~60 menit (30 menit baca + 30 menit kerjakan latihan)

## Prasyarat

- Sudah selesai Modul 1 (Selamat Datang & Potensi DA)
- Sudah selesai Modul 2 (Diferensiasi Profesi Data)
- Sudah punya catatan refleksi dari Modul 1

## Format Output

- `materi.md` — modul tertulis (~2,500 kata)
- `latihan/template-career-statement.md` — template diisi peserta
- `latihan/template-skill-mapping.md` — template self-assessment
- `cheatsheet.md` — formula Career Statement
- `mentor-notes.md` — briefing mentor

## Struktur Konten

| Section | Topik |
|---|---|
| 1 | Apa itu Career Statement & Kenapa Penting |
| 2 | Anatomi Career Statement Yang Baik |
| 3 | Template & 5 Contoh Real |
| 4 | Latihan: Tulis Career Statement Kamu |
| 5 | Skill Mapping — Self Assessment |
| 6 | Target Role Spesifik — Cari di LinkedIn |
| 7 | Closing & Selamat Datang di Week 1 |

## Output Peserta (untuk Portfolio)

Setelah modul ini, peserta punya 3 file di portofolio personal:

```
data-analyst-portfolio/
└── 00-career-statement/
    ├── career-statement.md
    ├── skill-mapping.md
    └── target-role-job-description.md
```
