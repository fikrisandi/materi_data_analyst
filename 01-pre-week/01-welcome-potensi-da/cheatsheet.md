# Cheatsheet — Pre-Week Modul 1

> Ringkasan 1 halaman. Pakai sebagai recap cepat sebelum lanjut ke Modul 2.

## 5 Pesan Inti

1. **Data Analyst = jembatan antara data mentah dan keputusan bisnis.** Bukan tukang ngolah angka.
2. **Skill DA berlaku di semua profesi**, bukan hanya untuk yang ingin jadi DA full-time (HR, marketing, finance, ops, founder — semua butuh).
3. **Pasar kerja DA Indonesia 2026: 5,000+ lowongan aktif** di LinkedIn, tumbuh 30%+ year-over-year.
4. **Range gaji**: Junior 6–12 jt → Senior 22–40 jt → Manager 50–100+ jt (Jakarta). Skill kombinasi (DA + cloud / DA + AI) bisa boost 20–40%.
5. **Background tidak harus IT** — banyak DA dari statistik, ekonomi, manajemen, teknik industri, akuntansi, bahkan sastra.

## 4 Tugas Utama Data Analyst

```
Data Sources  →  Analyst  →  Insight  →  Decision
   Database    Clean        Pattern     Action
   Files       Analyze      Trend       Strategy
   API         Visualize    Anomaly     Decision
   Scraping    Storytell    Number
```

## 8 Tugas Pokok DA Sehari-hari

1. Tarik data sesuai permintaan stakeholder (SQL, Excel)
2. Bersihkan data (Pandas, SQL)
3. Eksplorasi awal — EDA (Python, Statistics)
4. Analisis lanjutan — segmentasi, cohort, A/B test (SQL, Python)
5. Bangun dashboard (Tableau / PBI / Looker)
6. Bikin report & presentasi (storytelling)
7. Kolaborasi lintas tim (komunikasi)
8. Dokumentasi (technical writing)

## Hybrid Role — DA Skill di Profesi Lain

- **HR + DA** → People Analytics (attrition, salary benchmark)
- **Marketing + DA** → Growth Analytics (funnel, A/B test)
- **Finance + DA** → Automation Reporting (otomatisasi report bulanan)
- **Operations + DA** → Operations Analytics (capacity, supply chain)
- **Founder + DA** → Self-aware decision (dashboard penjualan sendiri)
