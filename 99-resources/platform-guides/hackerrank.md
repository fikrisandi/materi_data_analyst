# HackerRank — Panduan untuk Peserta DA

## Mengapa HackerRank?

- **Sertifikasi gratis** yang diakui industri
- Bank soal SQL & Python besar
- Tracking progress per skill
- Bisa dipakai sebagai bargaining chip negosiasi gaji entry level

## Sertifikasi Target untuk DA

| Sertifikasi | Durasi Test | Topik |
|---|---|---|
| **SQL (Basic)** | 60 min | SELECT, WHERE, ORDER BY, basic JOIN |
| **SQL (Intermediate)** | 60 min | GROUP BY, advanced JOIN, subquery, CTE |
| **SQL (Advanced)** | 90 min | Window function, complex query optimization |
| **Python (Basic)** | 60 min | Syntax, control flow, function |
| **Problem Solving (Basic)** | 90 min | Algorithm thinking, data structure |

## Roadmap Suggestion

### Week 1 (selesai SQL Basics)
- Tackle: HackerRank SQL "Basic Select" challenges (gratis, ~10 soal)
- Goal: 8/10 minimum solved

### End of Week 1
- Take **SQL (Basic) Skills Certification**

### Week 2 Day 4 (selesai SQL Advanced)
- Tackle: HackerRank SQL "Aggregations", "Basic Join", "Advanced Join"
- Goal: 80%+ solved

### End of Week 2
- Take **SQL (Intermediate) Skills Certification**

### After Course
- Take **Python (Basic) Skills Certification** kalau belum
- Optional: SQL (Advanced) + Problem Solving certifications

## Tips Lulus Sertifikasi

1. **Practice 30+ problem dulu** sebelum take cert test
2. **Time management** — 60 min for 5-10 questions
3. **Read carefully** — soal HackerRank sering ada constraint kecil yang miss
4. **Test edge case** — empty input, NULL values, ties
5. **Submit setelah pass all test cases** — partial submit bisa pengaruh score
