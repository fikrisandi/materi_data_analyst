# Mentor Playbook — Savvys Education DA Course

## Filosofi Mengajar

1. **Pemula deserve good explanation** — tidak ada "stupid question". Semua pertanyaan dijawab dengan respect.
2. **Show, don't tell** — selalu demo & live coding, bukan slide one-way.
3. **Insight > Sintaks** — boleh peserta lupa exact syntax, tapi harus paham **kapan & kenapa pakai**.
4. **Connect to career** — sebut konteks dunia kerja real saat memungkinkan.
5. **Empathy for transition** — banyak peserta nervous. Tone yang bikin mereka safe.

---

## Per-Week Highlights

### Pre-Week
- **Critical untuk transisi karir.** Jangan dilewat dengan "ah cuma intro".
- Career Statement peserta = self-anchor. **Simpan, review lagi di Week 3.**

### Week 1
- **Day 1 AM (Setup)** = sering jadi blocker. Sediakan extra time. Pair-up peserta.
- **Day 2 (Excel)** jangan diremehkan. Banyak yang ngaku "sudah bisa Excel" tapi belum kuasai pivot/VLOOKUP.
- **Day 3 (SQL)** = inti karir DA. Kalau peserta struggle, alokasikan extra.
- **Day 4 (Stats)** = bisa terasa abstrak. Selalu bawa kembali ke konteks bisnis.

### Week 2
- **Day 1 (Python intro)** = hindari overwhelm. Fokus subset Python untuk DA.
- **Day 3 (Pandas)** = where DA real magic happens. Banyak hands-on.
- **Day 4 (SQL Advanced + BigQuery)** = window function adalah game changer. Pastikan paham.

### Week 3
- **Day 1 (Scraping/API)** = fokus etika dulu, teknis kedua.
- **Day 2 (Stats Inferential)** = paling abstrak di kursus. Pakai analogi banyak.
- **Day 3 (Mentoring)** = kritikal. Review individual progress, identify gap.
- **Week 3 = titik motivasi paling rentan.** Watch for dropout signal.

### Week 4
- **Day 1-2 (BI Tools)** = fun & visual. Peserta biasanya excited.
- **Day 3 (Storytelling)** = pembeda DA biasa vs DA strategic. Push peserta untuk articulate insight, bukan cuma show angka.
- **Day 4 (Capstone presentation)** = puncak kursus. Setiap peserta dapat 10 min spotlight.

## Common Issues per Sesi

| Sesi | Issue Sering | Solusi |
|---|---|---|
| Day 1 AM Setup | conda not recognized, PATH issue | Pair up dengan peserta yang sudah berhasil |
| Day 1 PM Git | "git push minta password" | Setup SSH key, atau pakai PAT |
| Day 2 Excel | Pivot table tidak ke-update | Pastikan pakai Excel Table, refresh manual |
| Day 3 SQL | Result kosong | Cek WHERE clause, especially string case-sensitivity |
| Week 2 Day 3 Pandas | `df["col"] = df["x"] + df["y"]` tapi error | Cek dtype kolom, mungkin string vs numeric |
| Week 3 Stats | "p > 0.05 berarti tidak ada effect?" | Edukasi: gagal reject ≠ accept null |
| Week 4 BI | Dashboard slow | Filter data dulu sebelum load ke BI tool |

---

## Red Flag — Peserta yang Butuh Extra Support

1. **Belum push portfolio** by end of Week 1 — usually struggle dengan basic tooling
2. **Insight cuma report angka** by end of Week 2 — kurang business framing
3. **Skip Pre-Week** — biasanya hilang motivasi di tengah
4. **Selalu pakai chatbot AI untuk semua jawaban** — kurang understanding
5. **Tidak attend mentoring Week 3** — disconnect signal

Action: 1-on-1 check-in extra. Cek apakah perlu pace lebih lambat atau bantuan teknis spesifik.

---

## Tips Public Speaking di Live Class

1. **Recap 5 menit di awal** sesi — connect ke materi sebelumnya
2. **Pause untuk pertanyaan** tiap 15 menit
3. **Live code, jangan paste** dari prepared file — peserta belajar dari debugging mentor juga
4. **Sebut nama peserta** saat answer pertanyaan — bikin engagement naik
5. **End dengan teaser** — apa yang akan dipelajari sesi berikutnya
