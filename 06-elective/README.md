# Elective — Self-Paced Advanced Modules

## Tujuan

Materi tambahan yang **tidak wajib** diselesaikan selama 4 minggu kursus, tapi recommended untuk **deepen skill di tools spesifik** sesuai target karir.

Setiap modul self-paced, ~3-5 jam.

## Daftar Modul

| Folder | Topik | Cocok untuk |
|---|---|---|
| `power-bi-advanced/` | DAX advanced, time intelligence, custom visual | Target industri: banking, BUMN, korporat |
| `looker-studio-advanced/` | Custom calculation, BigQuery integration, embed | Target industri: tech, e-commerce, Google ecosystem |

## Cara Pakai

1. Selesai dulu Week 1-4
2. Pilih elective sesuai target industri
3. Self-paced — alokasikan 3-5 jam per modul
4. Output → tambahkan ke `06-visualization/` di portfolio
